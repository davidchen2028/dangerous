# 平台小游戏全宽底表布局设计

## 背景

当前平台小游戏通过 `layout()` 将可行走路径设置为画布宽度的 86%，导致左右出现宽空气墙。绿色表面贴图只绘制在该内部路径上，视觉上不连续；最近的贴图调整还将表面限制为顶部 36px 条带，因此需要统一扩大绘制与碰撞范围。

## 目标

- 绿色植被表面从画布左边连续铺到右边，不出现两侧空气墙或瓦片间的空隙。
- 角色可行走范围同步扩展到画布边缘。
- 缺口、门、机关、陷阱和移动物体继续基于同一个 `layout()` 坐标系，保持关卡行为一致。
- 录制陷阱回放与普通关卡使用相同的全宽视觉布局。

## 方案

将 `layout()` 的路径设置为 `pathX = 0`、`pathW = W`，保留现有 `pathY` 与 `pathH`。`drawFloor()` 和 `drawTrapPlayback()` 继续以 `L.pathX/L.pathW` 绘制泥土与表面贴图，并把表面限制在顶部 36px 条带；由于路径已全宽，贴图会连续覆盖整行。现有移动边界、缺口计算、门位置和机关位置均引用 `L`，会自然扩展到全宽，无需另设边界常量。

## 验证

- 使用 JavaScript 语法检查确认文件可解析。
- 在浏览器中打开小游戏，检查绿色顶部表面从左到右连续，无两侧留白。
- 操作角色移动到左右边缘，确认不会在旧的 7% 内缩位置被阻挡。
- 抽查含缺口、门和陷阱的关卡，确认缺口仍能掉落、门仍可进入、陷阱位置未偏移。
