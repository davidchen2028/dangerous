# 平台小游戏地表植物装饰设计

## 背景

当前小游戏地表只有绿色表面和泥土纹理，画面重复度较高。用户选定使用 Kenney Pixel Platformer 中的 `tile_0124`、`tile_0125` 增加植物装饰，并选择分组点缀、固定分布；小蘑菇 `tile_0128` 已排除。

## 目标

- 在地表增加固定位置的植物小组，丰富视觉层次。
- 使用项目内置资源，不依赖运行机器上的 Downloads 路径。
- 植物仅为视觉装饰，不参与碰撞，不改变角色、门、缺口、刺或动态箱子的行为。
- 植物分布避开门、缺口、刺和动态物体的关键区域。
- 普通关卡与陷阱回放保持一致的地表装饰风格。

## 方案

将两个植物素材复制到 `img/platform-scene/`，由 `sceneSprites` 统一加载。新增每关固定装饰配置，配置使用相对路径宽度比例和植物类型，不写死单一画布像素坐标；绘制时根据当前 `layout()` 转换为画布坐标，因此可适配不同窗口尺寸。每个植物按缩小后的像素尺寸绘制，底边对齐地表顶边，且设置纯视觉层，不加入 `isSupported()`、`resolvePitWalls()` 或任何碰撞列表。

装饰配置按关卡逐关定义。缺口、门、刺或关卡特殊机制占用的区段留出安全间距；没有安全位置的特殊关卡减少植物数量。绘制顺序放在地面之后、角色和机关之前，使植物自然贴在地表上，但不会遮挡角色主体。

## 验证

- 检查两个植物素材已存在于项目资源目录，且脚本在资源加载失败时仍可正常运行。
- 使用 `node --check js/platform-minigame.js` 和 `git diff --check`。
- 检查每一关植物位置固定、没有覆盖门/缺口/刺和动态箱子。
- 操作角色通过植物区域，确认植物不产生碰撞、不改变跳跃和掉落行为。
- 检查窗口缩放后植物仍贴合地表，不出现小数缩放导致的明显边缘闪烁。
