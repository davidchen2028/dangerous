# 极危行动 — 联机大厅

暗色行动基地背景 + **联机大厅**（WebSocket）。

## 功能

- 昵称进入、**房间号**（相同房间才能一起玩）
- 右上角 **在线玩家列表**
- 右下角 **聊天**
- **仓库 6×10**：左侧身上装备栏 + 右侧储物格，市场购入先入仓库
- **聊天 & 在线列表**：同房间可见

## 运行（联机）

见 **`复制到终端.txt`**，或：

```bash
cd "/Users/admin/project/david/极危/极危行动"
./run.sh
```

本机：**http://localhost:8080**

### 和好友联机

1. 主机运行 `./run.sh`（`--host 0.0.0.0` 已开启局域网）
2. 查本机 IP：`ipconfig getifaddr en0` 或 `./get-ip.sh`
3. 好友浏览器打开 `http://你的IP:8080`（也可用 `PORT=8082 ./run.sh` 换端口）
4. **房间号一致**（默认 `main`）

### 手机能用吗？

**可以。** 与电脑是**同一个网页**，已做手机适配：

| 设备 | 用法 |
|------|------|
| **电脑** | Chrome / Safari 打开 `http://localhost:端口` |
| **手机（同一 WiFi）** | Safari / Chrome 打开 `http://电脑IP:端口` |
| **操作** | 点「房间」「仓库」；右上角 × 返回；输入框字号已防 iOS 放大 |

注意：须先在本机运行 `./run.sh`，手机不能只打开 html 文件。

## 管理员：用户在线时长（仅自己）

在运行 `./run.sh` 前设置环境变量（不要提交到 Git）：

```bash
export JIWEI_ADMIN_KEY='请换成一长串随机密码'
export JIWEI_ADMIN_LOCAL_ONLY=1   # 可选：仅允许本机 127.0.0.1 访问

# 终端 1：游戏大厅（8080）
./run.sh

# 终端 2：在线统计管理（8082）
./run-admin.sh
```

浏览器打开管理页（把密钥换成你设的）：

`http://127.0.0.1:8082/admin/online-stats?key=你的密钥`

游戏仍用 **8080**：`http://127.0.0.1:8080`

页面会列出所有注册昵称、累计在线时长、是否在线、最后活跃与注册时间。从启用该功能后起算；用户登录大厅即开始计时，断开或退出后计入。

管理操作：**踢下线**；**封禁账号 1/5 天**；**封禁 IP 1/5 天**（按用户最近登录 IP，同 IP 均无法连接）；对应解封按钮。
